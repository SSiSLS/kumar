3. FACTS Docker Install

Replace UNAME below with your macOS / Linux username.

Step 1 — Create the base folder where FACTS will live

mkdir -p /Users/UNAME/Desktop/facts_ssisls


Step 2 — Clone the demo/ssisls branch

cd /Users/UNAME/Desktop/facts_ssisls
git clone --branch demo/ssisls https://github.com/pkjr002/facts.git


Step 3 — Build the FACTS Docker image & launch a container

Confirm your current directory with pwd. You want to be in the facts folder.

cd /Users/UNAME/Desktop/facts_ssisls/facts

Then run:

bash docker/launch_container.sh

💡 If you hit a permission error, run chmod +x docker/launch_container.sh first.


On success you should see:

#############################################
 #                                           #
 #   Welcome to the FACTS docker container   #
 #                                           #
 #############################################

 (factsVe) jovyan@fa559e5faa66:/opt/facts$


4. Run an Experiment

From inside the container shell ((factsVe) jovyan@...:/opt/facts$):

Run the dummy experiment — quick sanity check that the environment is wired up correctly.

bash submit_ssisls_experiment.sh dummy


Run the ssp global experiments.

bash submit_ssisls_experiment.sh ssp585


bash submit_ssisls_experiment.sh ssp126


bash submit_ssisls_experiment.sh ssp245


5. Visualize FACTS output Data

Use the FACTS.Visualization.dashboard.
1. To see global projections. 2. A table of component contributors (AIS, GrIS,glaciers etc).

Get the dashboard from github and run with docker.

cd /Users/UNAME/Desktop/facts_ssisls
git clone https://github.com/Ttheegela/facts.plotting.dashboard.git


Build the docker Image.

cd /Users/UNAME/Desktop/facts_ssisls/facts.plotting.dashboard
bash docker/build.sh


Run the container (like below), which produces an HTML file.

bash docker/run.sh --ssp-dir /Users/UNAME/Desktop/facts_ssisls/facts/experiments_ssisls/ssp585/
