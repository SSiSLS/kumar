# FACTS Projections Contributions
This file contains links to a reading list of FACTS publications. The most updated version will reside at [facts.postprocess.pub](https://github.com/facts-workbench/facts.postprocess.pub/edit/main/projects/FACTS_pub/facts.pub.md). I have categorized them to improve readability.
